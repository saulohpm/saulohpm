### 🚀 Projeto em destaque

**[numerical_methods](https://github.com/saulohpm/numerical_methods)** — biblioteca Python de métodos numéricos, estruturada como pacote instalável (src-layout, testes, notebooks de exemplo e benchmark)

- **Integração**: retângulo, trapézio, Simpson (1ª e 2ª), Monte Carlo, Gauss-Legendre
- **Diferenciação**: diferenças finitas (fórmula fechada de ordem n), extrapolação de Richardson
- **Séries**: Taylor, Fourier
- **Raízes**: bisseção, Newton-Raphson, Ridders
- **Álgebra linear**: jacobiano, decomposição de Cholesky, com métodos alternativos selecionáveis (Gauss/LU/Cholesky) — em expansão para incluir LU, QR, métodos iterativos (Jacobi, Gauss-Seidel, gradientes conjugados) e sistemas não-lineares

> Inclui um caso interessante de depuração numérica: correção de um bug de diferenças finitas encadeadas que amplificava erro de arredondamento, substituído por uma fórmula fechada de diferença central, além do ajuste de escala do passo por ordem da derivada para estabilizar a precisão em testes de série de Taylor.
